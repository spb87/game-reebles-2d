# Test plan

High-level testing strategy for the project.

## Unit tests

- Framework: {e.g., pytest, vitest, jest}
- Convention: {e.g., co-located with source files}

## Integration tests

- Framework: Playwright
- Scope: critical user flows

## Verification standard

Every task's exit criteria should be verifiable in ≤3 commands. If verification requires a long manual sequence, the task is too big or the exit criteria are underspecified.
